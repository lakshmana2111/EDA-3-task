# 📈 EDA-Stock-Analysis

An Exploratory Data Analysis (EDA) project focused on analyzing stock market data to uncover trends, volatility, and potential correlations. This repository contains the Jupyter Notebook (`Stock_analysis.ipynb`) where the complete analysis is performed.

## 📋 Overview

This project performs a comprehensive Exploratory Data Analysis on stock price data. The main goal is to visualize key metrics, understand data distributions, identify patterns, and generate insights that may support further financial analysis or machine learning modeling.

## 🔍 Key Objectives

* **Data Cleaning:** Handle missing values and format date-related data.
* **Data Visualization:** Create charts to analyze stock price movements and trading volume.
* **Statistical Analysis:** Calculate returns, volatility, and moving averages.
* **Correlation Analysis:** Identify relationships between different stocks and financial metrics.
* **Trend Analysis:** Explore historical stock price patterns and market behavior.
